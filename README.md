# ashimodel

3D Character Model and Turntable scene created in Blender.

## Files
- `character_turntable.blend`: Blender project file containing:
  - 3D Anatomical Character Body & Sculpted Head (`Character_Body`)
  - Natural Parted Wavy Hairstyle (`Character_Hair`)
  - Mid-thigh Athletic Shorts (`Character_Shorts`)
  - Studio Turntable Pedestal (`Turntable_Base`)
  - 3-point Studio Lighting (Key, Fill, Rim) and Camera setup
  - Subsurface scattering skin shader with photographic facial projection mapping
- `actor_face_clean.png`: Cleaned and delighted facial projection texture.
